# Codex project guidance

For engineering tasks in this repository, follow `agents/orchestrator.md` and the active `PROJECT_CONTEXT.md`. Read the relevant source, specialist profiles, and skills as the task requires.

Create a TODO with an owner and verification criterion, retain its task ID, and finish with a report of actual checks and remaining work. Use `docs/process/TASK_WORKFLOW.md` for the durable local workflow.

Use the native `context-efficient-development` skill for source exploration and the `context-engineer` agent for a bounded investigation when useful. Retrieve scoped memory through `docs/memory/MEMORY_GUIDE.md`. Expand excerpts whenever contracts or evidence remain incomplete.

See `docs/process/CONTEXT_EFFICIENCY.md` for the shared context CLI, local MCP configuration, host permissions, and measurement limits.
