# Evidence and Context Budgets

Keep exact source text available behind every summary. Each excerpt needs its path, source digest or revision, and returned line range. A result that reaches its output budget must state that more material exists and provide its continuation reference. If a large line or contract cannot fit, request a wider budget or use the native source reader.

When investigating correctness, include the conditions before and after the changed expression, related callers, error handling, and data ownership boundaries. A summary of one path does not establish coverage of another path.

After the worktree changes, validate references again. Include uncommitted content in cache invalidation. Reuse a source already read only when its content and the reader's access remain the same.

For handoff, retain the task ID, acceptance criteria, open TODO, decisions, pending authorizations, changed files, failed or blocked checks, and the next step. Refer to complete artifacts through locations the receiving agent can access.

For efficiency comparisons, count all model input and output, subagent calls, retries, and tool discovery. Record cached input according to the provider's usage definition. Report byte and word counts as text-size measurements. Use host token telemetry when available and label estimates with their method.
